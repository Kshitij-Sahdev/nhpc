NHPC Catchment Alert Dashboard API Reference

Public endpoints exposed by the NHPC Catchment & Emergency Disaster Alert Platform. All endpoints return JSON format with explicit unit specifications.

GET /api/ai-summary /api/v1/ai-summary
AI Summary (Unit-Annotated)

Returns a comprehensive, highly detailed JSON summary of all 27 NHPC hydro project catchments, IMD 12km x 12km grid rainfall forecasts, active NDMA disaster alerts, and configured warning thresholds. Specifically structured for AI agent ingestion with explicit physical units and zero telemetry.

Physical Unit Specifications
rainfall
mm
Precipitation amount in millimeters (3h & 24h totals).
wind_speed
m/s
Wind gust speed in meters per second.
temperature
°C
Minimum and maximum temperatures in degrees Celsius.
spatial_grid_step
12km x 12km
Approximate 0.125° spatial grid resolution for IMD Mausamgram NWP model.
distance
km
Distance from NDMA alert polygon in kilometers.

GET /api/warnings
Warnings

Returns all active proximity warnings generated by the system, grouped by project site.

Response Codes
200 Returns array of project warnings.
GET /api/project/<project_id>
Project

Returns metadata and active warnings for a specific project site by numeric project ID.

GET /api/alert/<alert_id>
Alert

Returns metadata for a single alert identified by its alert ID.
