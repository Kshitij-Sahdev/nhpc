API Reference

Public endpoints exposed by the NDMA GeoAlert Dashboard. All endpoints return JSON.

GET /api/alert/<alert_id>
Alert

Returns metadata for a single alert identified by its numeric identifier.

Path Parameters
id required
integer
The numeric identifier associated with the alert.
Response
{
  "alert_id": 12,
  "alert_identifier": "2024091200001",
  "state_id": 3,
  "event": "Heavy Rainfall",
  "headline_en": "Heavy to very heavy rainfall expected ...",
  "urgency": "Immediate",
  "severity": "Severe",
  "certainty": "Likely",
  "effective": "2024-09-12T06:00:00+05:30",
  "onset": "2024-09-12T08:00:00+05:30",
  "expires": "2024-09-13T06:00:00+05:30",
  "polygons": ["28.5,77.1 28.6,77.3 ..."]
  "created_at": "2024-09-12T08:00:00+05:30",
}
Response Codes
200 Alert found and returned.
404 No alert found for the given identifier.
GET /api/warnings
Warnings

Returns all currently active proximity warnings generated by the system, grouped by project and ordered by alert count.

Response
[
  {
    "project_id": 4321,
    "project_name": "Site Alpha",
    "alerts": [
      {
        "alert_id": 12,
        "event": "Heavy Rainfall",
        "severity": "Severe",
        "expires": "Fri, 13 Sep 2024 06:00:00 GMT",
        "warning_type": "NEAR_ALERT_POLYGON",
        "distance_km": 23.41,
        "affected_sites": [
          {
            "site_type": "PROJECT",
            "site_name": "Site Alpha",
            "distance_km": 23.41
          },
          {
            "site_type": "GND",
            "site_name": "Alpha Dam",
            "distance_km": 18.72
          },
          {
            "site_type": "GND",
            "site_name": "Alpha Powerhouse",
            "distance_km": 25.93
          }
        ]
      }
    ]
  }
]
Warning Types
INSIDE_ALERT_POLYGON
—
The site falls within the alert's affected polygon. Distance is 0.
NEAR_ALERT_POLYGON
—
The site is within the configured proximity threshold.
Response Codes
200 Returns array of projects with warnings. Empty array if none.
GET /api/project/<project_id>
Project

Returns project metadata and all active proximity warnings for a specific project site, identified by its numeric project ID.

Path Parameters
project_id required
integer
The numeric ID associated with the project site.
Response Fields
project
object
Project metadata: project_id and project_name.
project_exists
boolean
Whether the project ID resolves to a known project.
warning_count
integer
Total number of active warnings for this project.
warnings
array
List of warning objects ordered by ascending distance_km.
